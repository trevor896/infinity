# Infinity Portfolio
A polished personal portfolio and creative showcase built to demonstrate front-end design ability, brand thinking, and digital execution in one place to present:
- creative and brand-focused work
- front-end development capability
- UI/UX thinking
- analytics and visual storytelling
- a professional online presence for freelance and professional opportunities

## Why this project matters
This portfolio is built to communicate a strong personal brand for me as developer, analyst and designer who blends:
- front-end development
- visual communication
- data-informed design thinking
- professional presentation skills
It is designed to help employers, clients, and collaborators quickly understand capability, style, and execution quality without needing a long introduction.

## Stack used

### Frontend
- HTML5
- CSS3
- JavaScript
- Responsive multi-page layout
- Accessible navigation and UI patterns

### Backend
- Node.js
- Express.js
- CORS and security middleware
- Contact form handling
- Structured API endpoints

### Data layer
- PostgreSQL support for dynamic content
- JSON fallback content for resilience and easier maintenance
- Content organized for future expansion

### Tools and workflow
- Git for version control
- VS Code development workflow
- Environment-based configuration for deployment
- Modular structure for future updates
